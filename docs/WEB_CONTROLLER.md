# Moolo スマホ Web コントローラー

## 仕組み

Raspberry Pi Zero 2 W 上で Flask Web サーバーを起動し、同じ Wi-Fi に接続したスマホのブラウザから Moolo を操作します。

```
スマホブラウザ
  │  HTTP POST /api/drive  (200 ms ごとに送信)
  │  HTTP POST /api/stop   (指を離したとき)
  ▼
Flask (0.0.0.0:8080)
  │
  ▼
MotorDriver → DRV8835-S → 左右モーター
```

### ウォッチドッグ

サーバー側でバックグラウンドスレッドが 50 ms ごとに「最後に受信したコマンドの時刻」を確認します。
0.5 秒以上コマンドが届かなければ自動的に `motor.stop()` を実行します。

クライアント（JS）は走行中 200 ms ごとにコマンドを再送するため、通信が正常なかぎりウォッチドッグは発火しません。
通信が途切れた場合は 0.5 秒以内にモーターが停止します。

## 起動方法

### 1. Pi 上でサーバーを起動する

```bash
bash scripts/run_web_controller.sh
```

起動すると、アクセス URL が表示されます。

```
============================================
  Moolo Web Controller
============================================
  http://192.168.1.42:8080
  スマホと Pi を同じ Wi-Fi に接続してください
  Ctrl+C で停止します
============================================
```

IP が表示されない場合は、別ターミナルで確認してください。

```bash
hostname -I
```

### 2. スマホからアクセスする

スマホと Pi が同じ Wi-Fi に接続されていることを確認し、ブラウザで次の URL を開きます。

```
http://<Pi の IP アドレス>:8080
```

例：`http://192.168.128.193:8080`

## 操作方法

| 操作 | 動作 |
|------|------|
| ▲ を押している間 | 前進 |
| ▼ を押している間 | 後退 |
| ◄ を押している間 | 左旋回 |
| ► を押している間 | 右旋回 |
| STOP を押す | 即時停止 |
| 速度スライダー | 速度調整（0.00〜0.50、初期値 0.20） |

- **ボタンを押している間だけ動きます。**
- 指を離すと必ず停止します。
- 最大速度は安全のため 0.5 に制限されています。

---

## 安全停止の仕組み

以下のいずれかの条件でモーターが停止します。

| 条件 | 停止方法 |
|------|----------|
| 指を離す | JS が `/api/stop` を送信 |
| ページを閉じる / タブを切り替える | `beforeunload` / `pagehide` で `navigator.sendBeacon('/api/stop')` |
| 画面が非表示になる | `visibilitychange` で `/api/stop` を送信 |
| 通信が途切れる | サーバーのウォッチドッグが 0.5 秒後に `motor.stop()` |
| Ctrl+C | `SIGINT` ハンドラが `motor.stop()` |
| 例外発生 | `finally` ブロックで `motor.stop()` |

## 最初のテスト手順

> **必ず車輪を浮かせた状態でテストしてください。**
> 床に置いたままでの初回テストは危険です。

1. Pi の電源を入れ、Wi-Fi に接続する。
2. `bash scripts/run_web_controller.sh` でサーバーを起動する。
3. スマホのブラウザで URL を開く。
4. 速度スライダーを最低（0.00）付近にして各ボタンを確認する。
5. 指を離したときにモーターが止まることを確認する。
6. ページを閉じたときにモーターが止まることを確認する。
7. 問題がなければ速度を上げて床置き低速テストを行う。

## トラブルシュート

### ブラウザで画面が開かない

- Pi と スマホが同じ Wi-Fi に接続されているか確認する。
- Pi 側でサーバーが起動しているか確認する。
- IP アドレスを `hostname -I` で再確認する。
- ファイアウォールが 8080 ポートをブロックしていないか確認する。

### ボタンを押してもモーターが動かない

- サーバーのターミナルにエラーが出ていないか確認する。
- MotorDriver の依存ライブラリ（`gpiozero`, `lgpio`）がインストールされているか確認する。
- GPIO 配線を確認する（[docs/WIRING.md](WIRING.md) 参照）。

### モーターがすぐ止まる（ウォッチドッグが誤発火）

- スマホと Pi 間の Wi-Fi 遅延が大きい可能性があります。
- `web_controller.py` の `WATCHDOG_TIMEOUT` を `1.0` 秒程度に増やしてみてください。
- `DRIVE_INTERVAL_MS` を JS 側で `100` 程度に短くしても改善することがあります。

### Ctrl+C で止まらない

- `kill -SIGTERM <PID>` を試してください。
- Pi を再起動する場合は `sudo reboot`。
